# 密码学基础（区块链核心）
## 1. 哈希函数 Hash Function
特点：
- 单向性：只能明文→哈希，无法哈希反推原文
- 定长输出：无论输入多长，输出长度固定
- 抗碰撞：很难找到两段不同明文，哈希值相同
区块链常用：SHA-256

## 2. 非对称加密 Asymmetric Encryption
一对密钥：公钥 + 私钥
- 私钥：自己保管，不可泄露，用于签名
- 公钥：公开分发，用于验签
用途：区块链账户身份、数字签名

## 3. 数字签名 Digital Signature
流程：私钥签名 → 公钥验证
作用：证明消息是本人发出、没有被篡改。

## 4. 对称加密 Symmetric Encryption
加密解密用同一个密钥，加解密速度快，适合加密大量数据。

## 5. 默克尔树 Merkle Tree
叶子节点存储数据哈希，向上逐层合并哈希；
快速校验大批量数据是否被篡改，区块里交易数据常用。
